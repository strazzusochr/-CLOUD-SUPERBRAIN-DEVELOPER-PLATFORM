Route: `/files`

Goal: dense industrial knowledge surface matching `docs/reference/` direction. No project-status wall. Use dark control-room panels, thin borders, compact tables/lists, and restrained cyan/blue/green accents.

Required layout:
- Header with route purpose and DEV-ONLY/read-only state.

Element rules:
- Search input and button are real controls.
- Graph is decorative/read-only SVG with image role only.
- Purge/export/write actions stay absent or disabled with gate explanation.
- No Hetzner, GitKraken, Oracle active defaults.
